## Why

タブをクリックしてセッションを切り替えても、シェルの入力フォーカスはターミナルに移らない。もう一度ターミナル画面をクリックしないとキー入力できず、タブ切り替えのたびに一手間かかる。

## What Changes

- タブをクリックしてセッションを選んだとき、表示中のターミナル（xterm）にキーボードフォーカスを移し、すぐ入力できる状態にする
- すでにアクティブなタブの再クリック、`Cmd+1`〜`9` による切り替え、新規タブ作成でも同様にフォーカスする
- 設定モーダルやタブメモ編集が開いているときは、その入力欄からフォーカスを奪わない
- タブの見た目、セッション切り替えそのもの、コピー／ペーストの挙動は変えない

## Capabilities

### New Capabilities

- （なし）

### Modified Capabilities

- `terminal-ui`: タブ選択（クリック / `Cmd+1..9` / 新規タブ）後にアクティブなターミナルへキーボードフォーカスを移すことを要件にする。モーダル表示中はフォーカスを奪わない

## Impact

- Frontend: `App` のタブ選択経路と `TerminalView` の xterm `focus()`、関連テスト
- Backend / sessions / config API / desktop shell: 変更なし
